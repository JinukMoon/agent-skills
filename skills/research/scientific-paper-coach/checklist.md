# Scientific Paper Review Checklist

SNU "이공계 학생을 위한 영어 논문 작성법" (모윤숙·이지영·정한별 교수) 강의 1~13차시 + 실시간 세션 전체에서 추출한 **검증 가능한 심사 기준**.
각 항목 끝의 괄호는 근거 차시. 판정은 PASS / FAIL / N/A 로 한다. 강의 가르침이 기준이며, 분야 관례와 충돌하면 둘 다 언급한다.

---

## 0. 전체 구조 (Overall Structure)

- [ ] 논문이 모래시계(hourglass) 구조를 따르는가 — Introduction(broad→narrow), Methodology/Results(가장 좁음), Discussion(narrow→broad) (1차시, 13차시)
- [ ] Introduction과 Discussion이 대칭(symmetrical: getting in / getting out)을 이루는가 — 서론의 gap을 토론에서 답하는가 (1차시, 8차시)
- [ ] Methodology 위치가 분야 관례에 맞는가 (Bio/Chem/Med은 앞, 일부 공학·OA 저널은 Discussion 뒤, Science/Nature는 online supplementary) (1차시)
- [ ] 각 섹션이 자기 역할(무엇을/어떻게 vs 무엇을 의미하는가)을 지키는가 — Results=what, Discussion=what it means (7차시, 8차시)
- [ ] 투고 대상 저널이 권장하는 섹션 구성(Results/Discussion/Conclusion 분리 또는 통합)을 따르는가 (7차시, 8차시)

## 0-1. 연구 설계 (Research Design) — 본문에서 검증 가능할 때

- [ ] 독립변수(independent variable)를 한 번에 하나만 조작했는가 (1차시)
- [ ] 종속변수(dependent variable)가 명확히 측정·기술되었는가 (1차시)
- [ ] 통제한 상수(constants)가 모두 논문에 명시되었는가 (1차시)
- [ ] 대조군(control group)과 실험군(experimental group)이 모두 존재하며, 실험군이 조작을 제외하면 대조군과 동일한가 (1차시)
- [ ] 가설이 과학적 근거에 기반한 예측이며 H0/H1이 짝으로 성립하는가 (해당 시) (1차시, 실시간1)
- [ ] research question이 4조건을 만족하는가 — not too broad/narrow, original & interesting, well-focused & clear, not too easy/complex (1차시)

---

## 1. Title (제목)

- [ ] 제목이 핵심 키워드를 포함하고 그것을 앞부분(beginning)에 배치했는가 (4차시)
- [ ] 제목 길이가 적절한가 — 평균 약 16.6단어, 50~140자 범위 (4차시)
- [ ] 제목 형식(명사구 / 문장 / 의문문)이 내용에 맞게 선택되었는가 — 문장형은 답이 복잡하지 않을 때만, 의문문형은 간단한 답이 없을 때만 (4차시)
- [ ] 명사구 제목에서 명사 나열이 3단어를 넘지 않는가 — 길면 of/by/for 등 전치사로 관계를 명확히 했는가 (4차시)
- [ ] 명사를 형용사로 쓸 때 단수형을 썼는가 (dog food O, dogs food X / herbivore disturbance O) (4차시)
- [ ] 명사구 제목에 중의성(ambiguity)이 없는가 — "enzymatic activity suppression"처럼 of/by 해석이 갈리지 않는가 (4차시)
- [ ] 콜론(:)·대시(–)로 핵심어 앞부분과 설명형 부제를 적절히 구분했는가 (해당 시) (4차시)
- [ ] 제목에 축약어(abbreviation)를 쓰지 않았는가 (널리 인정된 것은 예외 가능) (9차시)
- [ ] 제목이 독립변수·종속변수·연구 맥락·결과 힌트 중 핵심 정보를 담고 있는가 (13차시)

## 2. Keywords & Highlights (키워드·하이라이트)

- [ ] 키워드가 3~4개이며 연구 핵심 개념을 대표하는 단어/짧은 구인가 (4차시)
- [ ] 키워드 선정 시 독자 검색어뿐 아니라 심사위원(editor가 referee 고를 때)을 고려했는가 (4차시)
- [ ] 제목과 키워드 리스트의 단어 중복을 피해 검색 커버리지를 분산했는가 (제목 2~3개, 키워드 6~8개) (실시간3)
- [ ] 하이라이트가 3~5개의 문장(bullet)이며 novel results 또는 new methods를 담았는가 (4차시)
- [ ] 키워드(단어)와 하이라이트(문장)를 혼동하지 않았는가 (4차시)

## 3. Abstract (초록)

- [ ] 초록이 논문 전체의 축소판(miniature)이며 완결된 한 문단 형태인가 (4차시, 13차시)
- [ ] 초록에 핵심 요소가 순서대로 들어갔는가 — background, purpose/scope, methods, key results, conclusion/implication (4차시)
- [ ] 연구 공백(gap)을 언급한 뒤 반드시 "본 연구가 무엇을 했다"가 이어지는가 (4차시)
- [ ] 초록의 시제가 본문 해당 섹션과 일치하는가 — 배경/경향=현재완료, gap·함의=현재, 방법·결과=과거(+수동) (4차시, 13차시)
- [ ] 초록에 축약어를 거의 쓰지 않았는가 (긴 이름이 여러 번 반복될 때만 예외) (9차시, 13차시)
- [ ] 초록이 수동태·무거운 주어(top-heavy)를 남발하지 않고 능동·가벼운 주어를 적절히 썼는가 (실시간3)
- [ ] (structured abstract라면) Background/Objectives/Methods/Results/Conclusions 라벨이 저널 형식에 맞는가 (4차시, 실시간3)
- [ ] (graphical abstract 요구 시) 메인 메시지를 그림 하나로 전달하는가 (4차시, 13차시)

## 4. Introduction (서론)

### 4-1. 구조와 3대 요소
- [ ] 서론이 general-to-specific(broad-to-narrow) 구조를 따르는가 — 배경을 잔뜩 깔지 않고 top-down으로 첫 문장에 주제를 꺼냈는가 (2차시)
- [ ] 서론이 3대 요소를 모두 담는가 — what is known → what is unknown → what the current research is about (2차시, 13차시)
- [ ] Stage 4(현 연구 목적/목표)가 반드시 포함되었는가 (2차시, 3차시)
- [ ] (해당 시) Stage 5(기여 하이라이트)·Stage 6(논문 구성 매핑)이 흐름에 맞게 가감되었는가 (3차시)
- [ ] nested/layered 구조로 주제를 점점 좁혀가며 각 layer의 gap이 다음 layer를 동기화하는가 (2차시, 3차시)

### 4-2. Stage 1 (주제 소개·중요성)
- [ ] 서론 첫 문장이 주제 소개 + 중요성 강조를 동시에 하는가 (주제만 던지고 끝나지 않는가) (2차시)
- [ ] 주제의 중요성을 술부(predicate)에서 "has attracted/has been widely studied/has become a popular tool" 등으로 표현했는가 (2차시)

### 4-3. Stage 2 (선행연구 맥락)
- [ ] 선행연구를 중구난방 나열하지 않고 현 연구를 support하는 관련 연구만 선별했는가 (2차시)
- [ ] 이공계 표준인 information-prominent citation(괄호 reference)을 기본으로 썼는가 — author-prominent는 저자가 특별히 중요할 때만 (2차시, 10차시)
- [ ] reporting verb 선택이 선행연구 뉘앙스에 맞는가 (pointed out=중립 vs argued=강한 주장) (2차시)

### 4-4. Stage 3 (Gap / Research Niche)
- [ ] gap이 명확히 제시되어 현 연구의 동기(motivation)가 되는가 (3차시)
- [ ] gap 신호어(however/nevertheless/nonetheless/conversely/although/despite/in spite of)를 사용했는가 (3차시, 실시간1)
- [ ] gap 문장이 현재 또는 현재완료 시제로 쓰였는가 — 과거 시제로 써서 "지금은 유효하지 않을 수 있다"는 함의를 주지 않는가 (3차시)
- [ ] gap 지적이 정중한가 — fail/ignore/neglect/reject/refute 같은 단정어를 피하고 hedging(has not fully addressed, remains unexplored)을 썼는가 (실시간1)

### 4-5. Stage 4 (현 연구 목적)
- [ ] 현 연구 목적이 서론에서 가장 좁은(narrowest) 부분에서 명확히 진술되었는가 (3차시)
- [ ] impersonal 문체인가 — I/we를 dummy subject(this study, our work, the experiments reported here) 또는 수동태로 회피했는가, 또는 저널·분야 관례상 we 사용이 허용되는지 확인했는가 (3차시, 실시간1)
- [ ] Stage 4 시제가 적절한가 — 주로 단순 과거(연구 행위), 가끔 단순 현재(논문 기술 자체) (3차시)

### 4-6. 서론 일반
- [ ] 에디터/레프리의 4대 질문에 yes로 답할 수 있는가 — 기여가 새롭고 original한가, 저널 scope에 맞는가, 관련 연구 인식이 충분한가, 선행연구 위에 build됨을 보였는가 (2차시)

## 5. Methodology (방법론)

### 5-1. 목적·구성
- [ ] 다른 연구자가 재현(reproducibility)·복제(replicability)할 수 있을 만큼 충분히 구체적인가 (5차시)
- [ ] 방법의 적절성·결과 일반화 범위·데이터 신뢰도/타당도를 심사자가 판단할 정보를 제공하는가 (5차시)
- [ ] 하위 섹션(subsections)이 논리적 순서로 배치되었는가 (분야 관례 확인) (5차시, 13차시)
- [ ] Methods와 Results의 소제목(subheadings)이 일치하는가 (5차시)
- [ ] 목적을 앞세운 도입구(To generate an antibody to X, ...)로 방법-목적을 연결했는가 (5차시)
- [ ] 새 문단 첫 문장이 앞 문단 내용을 받아 연결하는가 (5차시)
- [ ] 전체 방법론 접근을 먼저 소개하고, 방법의 정당성(justify/validate)이 드러나는가 (13차시)

### 5-2. 재료·시약
- [ ] 재료의 정확한 사양·양·출처/준비방법을 모두 명시했는가 (5차시)
- [ ] 상표명(trade names)을 지양하고 일반명/화학명을 썼는가 (꼭 쓰면 첫 글자 대문자) (5차시)
- [ ] 생물 재료를 속(genus)·종(species)·균주(strain)로 정확히 기술했는가 (5차시)
- [ ] 시약 인용에 full name(host/clone) + (manufacturer, city, country) + Cat# + Lot#까지 구체화했는가 (5차시, 9차시)
- [ ] 화학물질의 순도(chemically pure grade, >99.5% 등)를 명시했는가 (5차시)

### 5-3. 절차·측정
- [ ] 하위 섹션이 없으면 시간순(chronological)으로 기술하고 연관 방법을 묶었는가 (5차시)
- [ ] 표준(standard) 방법을 썼다면 그 출처를 Reference에서 밝혔는가 (the method [ref]) (5차시)
- [ ] 유효숫자(significant figures)까지만 보고하고 측정 전 자리수를 다 적지 않았는가 (5차시)
- [ ] 통계가 아니라 데이터를 강조하는가 (통계는 데이터 부각 수단) (5차시)
- [ ] 방법론의 한계를 언급하되 그 영향을 최소화(minimize significance)했는가 — "결과에 크게 영향을 주지 않았다" (5차시)

### 5-4. 태(Voice)·문장
- [ ] 수동태를 적절히 쓰되 남용하지 않고 능동태와 혼용했는가 (5차시, 실시간3)
- [ ] 수동태는 타동사에만 적용했는가 (자동사를 수동태로 만들지 않았는가) (5차시)
- [ ] 능격동사(boil/break/change/increase 등)의 능동/수동 뉘앙스가 의도에 맞는가 (The glass broke vs was broken) (5차시)
- [ ] top-heavy 문장(긴 주어 + 끝의 짧은 수동태 동사)을 피했는가 — 필요시 콜론으로 나열했는가 (5차시, 실시간3)
- [ ] 반복되는 수동태/대명사/관계사절을 생략해 간결하게 썼는가 (The samples were collected and analyzed) (5차시)
- [ ] 행위자가 중요하지 않거나 인칭대명사가 거만/반복적일 때 수동태를 택했는가 (5차시, 실시간3)

## 6. Results — 시각자료 (Illustrations)

### 6-1. Table vs Figure 선택
- [ ] 정확한 수치/복잡한 비교/계산값이 중요하면 table, 패턴/shape이 중요하면 figure를 선택했는가 (6차시)
- [ ] 같은 데이터를 표와 그림으로 중복 제시하지 않았는가 (6차시, 7차시)

### 6-2. 그래프 종류
- [ ] bar graph와 histogram을 구별했는가 — histogram은 도수분포이며 막대를 붙여 그렸는가, bar graph는 독립 카테고리로 막대를 띄웠는가 (6차시)
- [ ] error bar의 SD vs SEM 선택이 적절한가 — 표본이 크면 SD 대신 SEM이 적절(SEM은 n이 클수록 작아짐) (6차시)
- [ ] scatter plot에 적절한 fitting model과 r^2(R-square)를 표시했는가 (6차시)
- [ ] pie chart가 절대값이 아닌 상대값(비율)을 표시하고 큰/중요한 것부터 정렬했는가 (6차시)
- [ ] boxplot이 five-number summary(최대·최소·상·하사분위수·중앙값)를 표시하는가 (6차시)
- [ ] radar chart에 격자선(gridline)을 넣었는가 (다변량 비교에 필수) (6차시)

### 6-3. 작성 원칙
- [ ] 모든 figure/table이 stand-alone인가 — 본문 없이도 이해되도록 title/legend/key/footnote를 담았는가 (6차시, 13차시)
- [ ] 그래프에 일반적으로 gridline을 넣지 않았는가 (radar는 예외) (6차시)
- [ ] 그래프에 데이터 값(숫자)을 불필요하게 표시하지 않았는가 — 정확값이 필수이고 축에서 근사 불가할 때만 (6차시)
- [ ] tick mark 간격이 적절한가 (0~100 범위에 0.1 단위 등 부적절한 눈금이 없는가) (6차시)
- [ ] table을 box로 두르지 않고 가로선으로 행 구분, 공백으로 열 구분했는가 (APA 권장; 분야 우선) (6차시)
- [ ] 설명문이 descriptive하되 자기 분야 은어(jargon)를 피했는가 (6차시)
- [ ] 같은 종류 그래프의 형식(스타일)이 논문 전반에 일관되는가 (6차시)
- [ ] figure와 table에 별도 번호를 매기고 본문 등장 순서대로 소개·번호화했는가 (6차시)

### 6-4. 캡션·제목
- [ ] figure caption은 그림 아래, table title은 표 위에 위치하는가 (6차시)
- [ ] 캡션/제목의 제목 부분이 구(phrase) 형태 + 마침표이고, 나머지 설명은 완전한 문장인가 (6차시)
- [ ] figure caption이 5요소(제목/세부정보/구성요소설명/단위·통계표기/기호설명)를 담는가 (6차시)
- [ ] table title이 4요소를 담고 더 자세한 내용은 표 아래 note로 뺐는가 (6차시)

### 6-5. Supplementary
- [ ] supplementary material이 본문 figure/table과 동일 기준으로 작성되고 본문에서 동일 방식으로 인용되는가 (6차시)
- [ ] supplementary는 저널 에디팅을 안 거치므로 저자가 품질을 책임지는 수준으로 작성했는가 (6차시)

## 7. Results — 본문 (Writing)

### 7-1. 구조·원칙
- [ ] 결과를 시간순이 아니라 중요한 결과 위주로 스토리화했는가 (7차시)
- [ ] 모든 결과를 나열하지 않고 목적에 안 맞거나 흥미 없는 것은 생략했는가 (7차시)
- [ ] 원치 않거나 예상치 못한 결과의 한계를 숨기지 않고 언급했는가 (신뢰도 향상) (7차시)
- [ ] raw 데이터가 아니라 mean과 standard deviation을 제시했는가 (variation/variance가 아님) (7차시, 실시간3)
- [ ] Opening(이전 섹션 리뷰/주요 발견 프리뷰) / Body(시각자료 기술+비교) / Closing(문제점+함의) 흐름을 갖추는가 (7차시)
- [ ] 본문에서 언급한 모든 figure/table을 빠짐없이 설명했는가 (5개 만들고 4개만 언급 금지) (7차시)

### 7-2. 언어·기능
- [ ] 평가 언어(evaluative language: striking, importantly, significant)를 사용해 독자가 다르게 해석하지 않게 했는가 (7차시)
- [ ] highlight(발견 강조)와 locate(시각자료 위치 표시) 기능이 구분되는가 (7차시)
- [ ] 발견을 기술할 때 과거형, 시각자료가 보여주는 것을 가리킬 때 현재형을 썼는가 (Figure X shows) (7차시)
- [ ] "Figure X shows that ... was ..."처럼 주절은 현재, 종속절은 과거인가 (7차시)
- [ ] 결과 해석(interpretation)을 최소화하고 본격 해석은 Discussion에 두었는가 (7차시)
- [ ] show만 반복하지 않고 shows/illustrates/displays/revealed 등 유의어로 다양화했는가 (7차시)
- [ ] 함의(implication)는 결과에서 짧게만 언급하고 Discussion에서 본격화했는가 (7차시)

## 8. Discussion (토론)

### 8-1. 구조
- [ ] Discussion이 narrow-to-broad(specific-to-general)로 전개되며 Introduction을 미러링하는가 (8차시)
- [ ] 6대 요소를 갖추는가 — 연구질문/가설 재진술 + 주요 결과 재요약(중요도순) + 해석(literature+speculation) + 한계 + 함의 + 추후연구 권고 (8차시)
- [ ] 결과가 여러 개면 요소 2~6을 각 결과 그룹마다 반복했는가 (8차시)
- [ ] 주요 결과가 원 가설을 지지하는지, 다른 연구와 agree/contrast하는지 비교했는가 (8차시)
- [ ] 한계를 얼버무리지 않고 정직하게 다뤘는가 (가설과 안 맞는 부분 포함) (8차시)
- [ ] 함의(implication)를 결과로부터 일반화하여 더 넓은 분야 맥락에서 제시했는가 (8차시)
- [ ] 추후 연구/실질적 응용 권고로 마무리했는가 (8차시)

### 8-2. 주장 강도 (Strength of Claims)
- [ ] 주장 강도를 주동사의 단어·시제 및 that절 동사 시제로 적절히 조절했는가 (8차시)
- [ ] 확실성에 맞는 조동사를 썼는가 — might < could < may < can < should < would < will < must (확실성 척도, 시제 아님) (8차시, 실시간3)
- [ ] 확실성 부사를 적절히 썼는가 — occasionally/possibly < probably/generally/usually < certainly/undoubtedly/definitely (8차시)
- [ ] 주장 동사(demonstrate/means/indicate/appears/suggest/implies/shows 등)가 결과 확신 수준에 맞는가 (8차시)
- [ ] may have been(가능성) vs must have been(확실)을 의도에 맞게 구분했는가 (8차시)
- [ ] must not(금지) ≠ does not have to(불필요), should(advisable/likely 두 의미) 함정을 피했는가 (8차시, 실시간3)
- [ ] 잘못된 조동사·시제 선택으로 핵심 메시지(take-home message)가 모호해지지 않았는가 (8차시)

## 9. Conclusion (결론)

- [ ] Conclusion 섹션 존재 여부를 확인했는가 — 없으면 Discussion 마지막 1~2문단이 결론 역할을 하는가 (8차시)
- [ ] 결론이 Discussion의 단순 복붙/요약이 아닌가 (더 압축된 문장으로 핵심만) (8차시, 13차시)
- [ ] 모든 finding을 다시 나열하지 않고 가장 중요한 결과만 제시(grand conclusion)했는가 (8차시, 13차시)
- [ ] take-home message 하나를 명확히 전달하며 핵심 결과의 중요성을 강조했는가 (8차시)
- [ ] 자기 기여를 책임감 있게 소유(own your contribution: this study clearly demonstrates 등)했는가 (8차시)
- [ ] 각 결론에 대한 증거를 요약하고 추후 연구로 마무리했는가 (8차시)

## 10. References & Citation (참고문헌·인용)

### 10-1. 표절·윤리
- [ ] 상식(common knowledge)이 아닌 정보·아이디어·방법·장비·알고리즘을 모두 인용했는가 (10차시)
- [ ] common knowledge 판단을 독자 기준으로 했는가 — 단일 원출처를 특정할 수 없는 것만 상식 (10차시, 실시간1)
- [ ] 확신이 없을 때 인용하는 쪽을 택했는가 (When in doubt, cite) (10차시, 실시간1)
- [ ] Trojan citation을 피했는가 — 원 연구의 진짜 기여 대신 사소한 포인트로만 인용하지 않았는가 (10차시, 실시간6)
- [ ] 인용을 투명하되 평가를 담아(transparent, not neutral) 포함 이유를 드러냈는가 (10차시)
- [ ] 잘못된 평가어로 선행연구를 deflate/inflate하지 않았는가 (10차시)
- [ ] self-citation을 자제하고 인용수 부풀리기로 쓰지 않았는가 (다른 인용보다 높은 기준) (10차시, 실시간6)

### 10-2. 인용 형식
- [ ] 인용한 모든 출처에 in-text citation과 full reference 양쪽을 표시했는가 (둘 다 필수) (10차시)
- [ ] 이공계 표준인 numeric 스타일 + information-prominent를 기본으로 썼는가 (해당 분야) (10차시, 2차시)
- [ ] in-text citation 스타일(author-date vs numeric)이 일관되는가 (10차시)
- [ ] full reference에 필수 요소(저자 전원, 연도, 제목, 저널, vol/page, 온라인이면 DOI)가 들어갔는가 (10차시)
- [ ] 저자 이름을 last name 기준으로 double-check하고 first name은 이니셜로 썼는가 (10차시)
- [ ] 저널의 Instructions/Information for Authors 형식을 따랐는가 (10차시)
- [ ] author-date면 제1저자 성 알파벳순, numeric이면 본문 등장 순으로 reference list를 정렬했는가 (10차시)
- [ ] Introduction에는 리뷰 논문, Discussion에는 실증 연구를 우선했는가 (10차시)
- [ ] 방법론 관련 인용을 Supplementary로 빼서 본문 참고문헌 수를 관리했는가 (해당 시) (10차시)

### 10-3. 추가 윤리 (실시간6)
- [ ] 투고 전 similarity check를 했는가 — IEEE 기준 전체 30% / 단일 출처 10% 초과 금지 (실시간6)
- [ ] 본문 참고문헌 수가 저널 가이드라인 범위인가 (Science/Nature 약 50개, Methods/Supp 별도) (실시간6)
- [ ] preprint는 arXiv/bioRxiv 등 공인 서버 것만 reference list에 넣고, in preparation은 본문에서만 언급했는가 (실시간6)

## 11. Summarizing & Paraphrasing (요약·바꿔쓰기)

- [ ] 요약(summary)과 패러프레이즈(paraphrase)를 구분했는가 — paraphrase는 원문과 길이·의미를 유지 (11차시)
- [ ] 요약/패러프레이즈 모두 자기 말 + 다른 문장 구조 + 아이디어 순서 재배열을 했는가 (11차시)
- [ ] 출처를 자기 말로 바꿔도 본문 + 참고문헌 양쪽에 인용했는가 (출처 표기만으로는 부족, 문장 그대로면 여전히 표절) (10차시, 11차시, 실시간6)
- [ ] 요약에 본인 생각/해석/평가를 넣지 않았는가 (공정하게, minor를 major로/major를 minor로 왜곡 금지) (11차시)
- [ ] 패러프레이즈에서 단어 일부 + 문법 구조(능동/수동, 구/절)를 함께 바꿨는가 (11차시, 실시간6)
- [ ] straw man fallacy를 피했는가 — 원문 주장을 과장·왜곡하지 않았는가 (11차시, 실시간6)
- [ ] 인용 강도를 왜곡하지 않았는가 — 원문의 hedging(may)을 단정(will)으로 바꾸지 않았는가 (실시간6)
- [ ] 좋은 요약 조건을 갖췄는가 — 출처 + 연구 주체 + 실험 내용 최소 구체성 + 결과, vague 표현 회피 (11차시)
- [ ] reporting verb 패턴(verb+noun 또는 verb+that절)과 시제(현재=현재 유효, 과거/완료=과거 연구)가 맞는가 (11차시)
- [ ] reporting verb 강도가 원저자 주장에 맞는가 — stated(중립)/argued·asserted(강한 지지)/challenged·refuted(강한 반대)/suggested(약함) (11차시, 실시간1)

## 12. 문장·문법·구두점 (Language & Punctuation)

### 12-1. 시제 (Tense) — 핵심
- [ ] 연구 논문에 present simple / present perfect / past simple 세 시제만 썼는가 (다른 시제는 오류 신호) (2차시, 실시간1)
- [ ] 단순 현재를 적절히 썼는가 — 불변의 사실/용어 정의/figure·table·수식 참조/연구 목적/결과의 의미·함의 (2차시, 13차시)
- [ ] 현재완료를 적절히 썼는가 — 주제 중요성/gap/여전히 유효한 선행연구 (과거~현재 연결) (2차시, 13차시)
- [ ] 단순 과거를 적절히 썼는가 — 현재와 무관한 선행연구 인용/본 연구의 방법·결과/더 이상 유효치 않은 사실 (2차시, 13차시)
- [ ] 현 논문의 새 발견(new findings)을 검증 전까지 present simple로 쓰지 않았는가 (실시간1)

### 12-2. 문장 종류·병렬
- [ ] 문장 종류(simple/compound/complex)를 올바르게 구성했는가 (4차시)
- [ ] 등위접속사(FANBOYS)로 문장을 시작하지 않았는가 (4차시)
- [ ] 병렬 구조가 지켜졌는가 — 등위/상관 접속사로 이어지는 항목의 문법 형태가 동일한가 (7차시)
- [ ] 동사가 요구하는 형태를 맞췄는가 (aimed → 반드시 to부정사, 동명사 불가) (7차시)
- [ ] 명사구 vs 형용사구 병렬이 일치하는가 (safety ↔ ease of use, easy to use/ease to use는 오답) (7차시)
- [ ] 상관접속사 양쪽 절 구조가 일치하는가 (not only ... but it also ...) (7차시)
- [ ] 3개 이상의 독립절을 등위접속사로 죽 잇지 않았는가 (9차시)

### 12-3. 콤마 (Comma)
- [ ] 도입어(Nonetheless, Considerably 등) 뒤에 introducer comma를 찍었는가 (9차시)
- [ ] 두 독립절을 콤마로 이을 때 FANBOYS를 썼는가 (but 자리에 however 쓰면 비문) (9차시)
- [ ] 두 번째 절에 주어가 없으면 콤마를 빼고 한 문장으로 이었는가 (9차시)
- [ ] because 앞에 불필요한 콤마를 찍지 않았는가 (FANBOYS 아님) (9차시)
- [ ] 3개 이상 병렬 항목을 series comma로 구분하고 항목이 2개면 콤마를 빼는가 (9차시)
- [ ] Oxford/Harvard comma(마지막 항목 앞 콤마)를 써서 동격/병렬 모호성을 없앴는가 (9차시)
- [ ] 비제한적(nonrestrictive) 삽입 요소를 inserter comma로 앞뒤 감쌌는가 (9차시, 3차시)
- [ ] 제품 표기를 (Manufacturer, City, Country) 형식으로 했는가 (9차시, 5차시)
- [ ] 날짜(Month Day, Year)·주소(City, State, Country) 콤마가 맞는가 (9차시)
- [ ] 등위 형용사 사이에 콤마(large, concrete)를 찍고, 누적 형용사(bright yellow)에는 안 찍었는가 (9차시)
- [ ] 제한적(restrictive) 수식어에는 콤마를 안 찍고, 비제한적에는 콤마를 찍었는가 (콤마가 의미를 바꿈) (3차시, 실시간1)

### 12-4. 세미콜론·콜론
- [ ] 세미콜론을 밀접한 두 독립절 사이/접속부사 앞/내부 콤마가 있는 항목 나열에 적절히 썼는가 (9차시)
- [ ] 접속부사(however, additionally, furthermore 등) 뒤에 콤마를 찍었는가 (but 뒤에는 콤마 없음) (9차시)
- [ ] 콜론을 완성된 문장 뒤에만 쓰고 전치사/동사 바로 뒤에 쓰지 않았는가 (9차시)
- [ ] 콜론을 부제 앞/예고된 나열 앞에 적절히 썼는가 (9차시)

### 12-5. 하이픈·대시·기타
- [ ] 하이픈을 음절(영어 발음 기준)로 나눠 줄 끝에 붙이고 줄 머리에 두지 않았는가 (9차시)
- [ ] 하이픈을 분수·21~99 숫자·화학 접두사·명사 앞 복합형용사에 적절히 썼는가 (9차시)
- [ ] dash(—)와 hyphen(-)을 혼용하지 않았는가 (pause 강도: 콤마 < dash < 세미콜론/온점) (9차시)
- [ ] 책·저널·학명 등 이탤릭이 필요한 곳에 이탤릭을 썼는가 (9차시)
- [ ] 괄호( )·대괄호[ ] 앞에 스페이스 한 칸을 두었는가 (9차시)

### 12-6. 축약·관사
- [ ] 축약을 최소화하고 첫 등장 시 풀네임 + (축약)으로 도입했는가 (9차시)
- [ ] 단위 축약을 수치와 함께일 때만 쓰고 단·복수 동일, 수치-단위 사이 스페이스를 두었는가 (4 mg) (9차시)
- [ ] a/an을 글자가 아닌 소리로 결정했는가 (an M.S., a master of science) (9차시)
- [ ] 화학 축약이 IUPAC를 따르는가 (9차시)

## 13. (부록) 투고·커버레터·이메일 (Submission)

- [ ] 투고 전 Where(저널)/What(원고+추가서류)/How(형식·word count·스타일)를 확인했는가 (12차시)
- [ ] predatory journal을 경계했는가 (큰 액수 publication fee, 먼저 투고 권유 등) (12차시)
- [ ] 동시 투고를 하지 않고 커버레터에 미출판·미투고를 명시했는가 (12차시)
- [ ] 원고를 블라인딩했는가 — 저자명, 문서 파일 속성, 레퍼런스 속 본인 저작까지 익명화 (12차시)
- [ ] 저널의 For Authors/formatting guide(기본 스타일 외 자체 가이드)를 따랐는가 (12차시)
- [ ] 첫 투고 커버레터가 7요소(scope 적합/제목·저자/신규·미투고/특이점 강조(초록 반복 금지)/편집자 의문점/프레젠테이션/리뷰 기대)를 담는가 (12차시)
- [ ] 재투고 커버레터가 수정 주요사항을 하이라이트하고 모든 리뷰어 코멘트에 답변했는가 (12차시, 실시간6)
- [ ] 공식 이메일이 5단계(구체적 제목/정중한 인사/I-statement 소개/명확·정중한 요청/감사+full name 맺음)를 갖췄는가 (12차시)
- [ ] 리뷰 코멘트를 개인 공격으로 받지 않고 핵심 메시지를 해치지 않는 선에서 수용했는가 (12차시)
- [ ] 커버레터 파일을 Word/PDF로 보냈는가 (해외에 hwp 금지) (12차시)
